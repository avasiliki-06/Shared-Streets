# Shared Streets — The Safer Destination

A static campaign presentation website for a Toronto sustainable transportation campaign connected to UN Sustainable Development Goal 11.

## Files

- `index.html` — website structure and content
- `styles.css` — all website styling and responsive layouts
- `script.js` — interactions, guided installation walkthroughs, cursor animation, image viewer, and scroll effects
- `images/` — campaign installation artwork, data visualization details, SDG 11 mark, and assignment research page images
- `assignment1-part1.pdf` — supporting research document

## Run locally

Keep the files and folders together. Open `index.html` in a browser, or use a local development server. No build step or package installation is required.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root (not just the ZIP).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

The page uses Google Fonts (DM Mono and Space Grotesk) from Google Fonts, so an internet connection is needed for those typefaces to load. The rest of the site is static.
